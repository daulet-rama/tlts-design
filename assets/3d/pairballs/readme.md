# Мячи пар (pair balls)

Пятнадцать рендеров двухцветного мяча пары — по одному на каждое сочетание уровней КПР без учёта порядка
(3.0, 3.5, 4.0, 4.5, 5.0). Половины окрашены цветами шкалы из `live-docs/CONTRACT.md`, раздел 2
(3.0 `#7FD3EA`, 3.5 `#19AFD6`, 4.0 `#E6E3DA`, 4.5 `#E07A4E`, 5.0 `#BF4F27`), между ними белый шов
по кривой теннисного мяча с b = 0.30 — та же математика, что в шейдере `s5-bold-pair-ball/index.html`.

## Файлы

| Файл | Что |
|---|---|
| `ball-AA-BB.webp` | 640×640, WebP с альфой (q 90), прозрачный фон. `AA` — меньший уровень (`30`, `35`, `40`, `45`, `50`), `BB` — больший; `ball-30-30` … `ball-50-50` |
| `ball-AA-BB-sm.webp` | 160×160, то же, уменьшено Lanczos |
| `manifest.json` | список мячей: id, уровни, цвета, пути; замер цвета по освещённой части |
| `sheet.jpg` | все 15 на одном листе (треугольная матрица уровней) — для проверки |
| `src/pairball.py` | меш, атрибут шва, материал войлока, ворс — общий модуль (его же берёт ключевой кадр) |
| `src/render_pairballs.py` | сцена, калибровка цвета, рендер, WebP, манифест, лист |
| `src/calib.json` | подобранное альбедо каждого уровня |

Ракурс один для всех: шов читается S-образной линией сверху вниз, половины видны поровну
(замер по пикселям — 45,7 % / 45,7 %, остальное шов). **Меньший уровень — всегда слева**, больший — справа.
Свет: мягкий ключевой сверху-слева, слабый заполняющий снизу-справа, лёгкий холодный контровой сзади-справа.
Тени на фоне нет.

## Цвет

Рендер в Cycles с view transform **Standard** (линейный отклик), альбедо каждого уровня подобрано так,
чтобы средний цвет освещённой части войлока (фиксированное пятно у ключевого света) совпал с цветом шкалы
с точностью до ~3/255 (`calibration` в манифесте). Поэтому альбедо в `calib.json` темнее канона — это нормально.

## Как пересобрать

    cd assets/3d/pairballs/src
    blender -b --factory-startup --python render_pairballs.py            # всё, ~1,5 мин
    blender -b --factory-startup --python render_pairballs.py -- --calib # заново подобрать цвета
    blender -b --factory-startup --python render_pairballs.py -- --only 30-50,45-45 --quick

Нужны Blender 5.2 и ffmpeg с libwebp (лист собирается ffmpeg, подписи — `drawtext`).
Промежуточные PNG — в `$PB_BUILD` (по умолчанию `<tmp>/tlts-pairballs-build`).
Ворс — кривые геометрических узлов на отдельном объекте Curves; `PB_FUZZ=0` отключает его.
