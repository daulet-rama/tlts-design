# Кубок Итогового TS CUP — 3D-модель для сайта (вариант trophy-opus)

Модель построена в Blender 5.2 скриптами из `src/` по фото настоящего кубка. Это восьмигранная расширяющаяся чаша со ступенчатым карнизом, тонкие ручки, гранёная ножка с пояском, ступенчатая база, полированный поясок с гравировкой и точёная подставка из сосны. Кубок сделан по образцу кубка ATP Finals.

## Модель

- **Оси и масштаб.** Y вверх, метры. Начало координат — в центре дна подставки. Трансформации применены: у всех узлов единичные матрицы.
- **Перед кубка** (табличка на чаше, гравировка на пояске) смотрит в **+Z**, то есть на камеру three.js по умолчанию.
- **Габариты:** 0,254 × 0,600 × 0,254 м (X × Y × Z).
- **Треугольники:** 17 066, вершин в glTF 14 936. Мешей 9, примитивов 13 (13 вызовов отрисовки).
- **Узлы:** корень `TS_CUP_Trophy` → `Plinth_Pine`, `Band_Engraved`, `Base_Ledge`, `Foot`, `Stem`, `Bowl`, `Rim`, `Handles`, `Badge`.
- **Нормали.** Все меши замкнуты, при обратном импорте у всех положительный объём и 0 перевёрнутых нормалей. Грани восьмигранника острые. Профили, поясок и подставка гладкие: на пояске после вырезания гравировки заданы аналитические нормали, поэтому вокруг букв нет пятен. Материалы односторонние (`doubleSided: false`).

### Материалы (PBR metallic-roughness, Principled BSDF)

| Имя в glTF | Где | baseColor (линейный) | metallic | roughness |
|---|---|---|---|---|
| `Silver925` | основной металл: чаша, венчик, ручки, воротник, кольцо, ножка, база, поясок | 0,94 / 0,935 / 0,92 | 1 | 0,12 |
| `Brass` | акцент: гранёный узел ножки | 0,96 / 0,68 / 0,28 | 1 | 0,20 |
| `BrassSatin` | акцент: матовая латунная табличка на чаше | 0,96 / 0,68 / 0,28 | 1 | 0,30 |
| `EngravingDark` | заливка гравировки (поясок, табличка) и риски пояска | 0,03 / 0,03 / 0,034 | 1 | 0,45 |
| `PineBase` | подставка: текстура `pine_basecolor`, JPEG 1024×1024, 153 КБ | текстура | 0 | 0,42 |

Почему серебро основное. На фото (photo-04, photo-11 и др.) кубок целиком зеркально-серебряный. Латунь оставлена на акцентах: узел ножки и табличка. Табличка сделана матовой с тёмной гравировкой, а не зеркальной с выпуклыми буквами. Грань чаши смотрит немного вниз и в зеркале отражала бы тёмный пол, и буквы пропадали бы. Так «TS CUP» читается при любом окружении.

Сосна тонирована в тёмный цвет, потому что на фото подставка почти чёрная. Волокна видны. Текстура запечена из процедурной древесины в объёмных координатах, поэтому на торцах видны годичные кольца, а на боках продольные волокна.

## Рекомендуемые настройки three.js (r160)

- `renderer.toneMapping = THREE.ACESFilmicToneMapping`. `outputColorSpace = THREE.SRGBColorSpace` (в r160 стоит по умолчанию).
- **Окружение обязательно.** Без `scene.environment` металл чёрный. Задавайте его через `PMREMGenerator`.
  - `studio_small_09_1k.hdr` даёт контрастное «зеркало», как на фото. Ставьте `toneMappingExposure` 1,15–1,3: чаша отражает и тёмные части студии.
  - `RoomEnvironment` даёт ровное светлое серебро. Ставьте `toneMappingExposure` 0,9–1,0.
- `envMapIntensity` = 1,0 для всех материалов. На тёмной странице можно 1,2–1,4.
- **Свет:** один `DirectionalLight` силой 1,0–1,5 сверху спереди, например `(0.6, 2.0, 1.4)`. Он даёт блики на венчике и ручках. Ambient не нужен.
- **Камера:** fov 22–28°, цель `(0, 0.30, 0)`, дистанция 1,6–2,1 м. Для героического ракурса опустите камеру до y ≈ 0,12–0,18.
- **В r160 нет** `scene.environmentIntensity` и `environmentRotation` (они появились в r162–r163). Яркость задаётся через `material.envMapIntensity`. Если нужен другой рисунок отражений, поворачивайте модель или камеру.
- **Тень.** Модель сама её не отбрасывает. Мягкую контактную тень можно сделать плоскостью с `ShadowMaterial` и `castShadow` у источника или блоб-текстурой.
- **Запасной вид.** На слабых телефонах и без WebGL показывайте `trophy-dark.jpg` или `trophy-hero.png`.

```js
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';

const canvas = document.querySelector('#trophy');
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true });
renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
renderer.setSize(canvas.clientWidth, canvas.clientHeight, false);
renderer.toneMapping = THREE.ACESFilmicToneMapping;
renderer.toneMappingExposure = 1.2;
renderer.outputColorSpace = THREE.SRGBColorSpace;

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(25, canvas.clientWidth / canvas.clientHeight, 0.05, 20);
camera.position.set(0.55, 0.42, 1.6);   // 3/4 немного сверху
camera.lookAt(0, 0.30, 0);

const pmrem = new THREE.PMREMGenerator(renderer);
new RGBELoader().load('../assets/3d/hdr/studio_small_09_1k.hdr', (hdr) => {
  hdr.mapping = THREE.EquirectangularReflectionMapping;
  scene.environment = pmrem.fromEquirectangular(hdr).texture;   // фон не трогаем: прозрачный canvas
  hdr.dispose();
  pmrem.dispose();
});

const key = new THREE.DirectionalLight(0xffffff, 1.2);
key.position.set(0.6, 2.0, 1.4);
scene.add(key);

let trophy;
new GLTFLoader().load('../assets/3d/trophy-opus/trophy.glb', (gltf) => {
  trophy = gltf.scene;                  // корень TS_CUP_Trophy, 0,6 м, низ в y = 0
  trophy.traverse((o) => {
    if (o.isMesh) o.material.envMapIntensity = 1.0;
  });
  scene.add(trophy);
});

renderer.setAnimationLoop((t) => {
  if (trophy) trophy.rotation.y = Math.sin(t / 4000) * 0.5;   // лёгкое покачивание
  renderer.render(scene, camera);
});
```

Пути в примере даны относительно страницы на один уровень ниже `design/site/` (`../assets/...`). Если страница лежит в другом месте, поправьте их.

Вариант без HDR: `scene.environment = pmrem.fromScene(new RoomEnvironment(renderer), 0.04).texture` (импорт `three/addons/environments/RoomEnvironment.js`), экспозиция 0,9–1,0.

Перекрасить в рантайме полностью в серебро, как настоящий кубок:

```js
trophy.traverse((o) => {
  if (o.isMesh && /^Brass/.test(o.material.name)) o.material.color.setRGB(0.94, 0.935, 0.92);
});
```

## Рендеры

- Cycles, OptiX (RTX 4070), 768 сэмплов с адаптивной выборкой, денойзер OpenImageDenoise. Цветовое преобразование Khronos PBR Neutral. Все 4 кадра считаются около 50 с.
- Основной свет — `studio_small_09_2k.hdr` (та же HDRI в 2k, лучше резкость отражений; 6,3 МБ, в папку сайта не клал). Поворот окружения: hero, front и dark — 180°, 3/4 — 120°.
- Дополнительно: мягкий верхний софтбокс 12 Вт, невидимый для камеры. У студийной HDRI тёмный потолок, и без софтбокса верх венчика выглядел бы чёрной полосой.
- Под кубком shadow catcher: контактная тень в альфа-канале PNG. В отражениях он выглядит как нейтральный серый пол, чтобы гравировка на пояске не терялась на чёрных пятнах HDRI.
- `trophy-dark.jpg` собран из прозрачного рендера на радиальном градиенте `#0f2d50` → `#040b16`.

## Проверка

1. **Обратный импорт в Blender** (`src/verify_glb.py`). 10 объектов: 9 мешей и пустой корень. 5 материалов, 17 066 треугольников, габариты 0,254 × 0,254 × 0,6 (Z-up), низ на 0. Объёмы всех мешей положительные, перевёрнутых нормалей 0. Совпадает с экспортом.
2. **Браузер.** Тестовая страница three.js r160 (import map на jsdelivr): GLB вшит в base64, загружается через `GLTFLoader.parse`, свет `RoomEnvironment` + `PMREMGenerator`. Вторая страница использует ту же HDRI через `RGBELoader`. Скриншоты сняты в headless Chrome на SwiftShader. Нормали в порядке, металлы не чёрные, кадр не тёмный. Табличка, гравировка, латунные акценты и текстура сосны читаются. Страница считает 13 мешей (three.js делит мультиматериальные меши), 17 066 треугольников, 0,254 × 0,600 × 0,254 м.

## Насколько похоже на настоящий кубок

Пропорции сняты с фото `storage__1275` (кубок 1155 px → 0,600 м) и `storage__1411`, сверены с `storage__1399` (photo-04), `1015`, `798`. Совпадает:

- восьмигранная чаша с выпуклым сужением книзу. Ширина на 11/27/49/72 % высоты чаши — 0,46/0,65/0,77/0,89 от верхней, модель повторяет этот профиль;
- ступенчатый восьмигранный карниз, свес около 30 % от ширины чаши;
- ручки из тонкого прутка: вертикально вниз от края венчика примерно на 0,10 м (на фото около 0,107 м), затем под 33° в чашу на 42 % её высоты;
- воротник и гранёный узел, вогнутая восьмигранная ножка на трёхступенчатой базе, высокий полированный поясок, точёная тёмная подставка;
- высоты секций — в пределах нескольких миллиметров от замеров при общем масштабе 0,6 м.

Отличия и достройки:

- **Нет лент «TLTS FINALS».** Это украшение церемонии, а не часть кубка. При необходимости их можно добавить отдельным узлом.
- **Поясок.** На настоящем пояске выгравированы мелкие имена победителей, здесь крупная надпись «TS CUP», как просили.
- **Табличка.** На настоящем кубке табличка серебряная с выпуклыми буквами. Здесь она латунная матовая с тёмной гравировкой — ради читаемости (см. выше).
- **Латунь.** Латунные акценты — дизайнерское решение по брифу «латунь с серебром». На фото весь кубок серебряный. Сборка `--scheme silver` убирает латунь полностью.
- **Подставка.** На фото она почти чёрная. Здесь тёмная сосна с видимыми волокнами, как в брифе.
- **Достроено.** Не видны на фото и достроены в духе ATP: число ступеней карниза и базы, точный профиль узла, стык ручки с венчиком, внутренность чаши.
- **Высота.** Реальная высота не измерена, масштаб 0,600 м взят по брифу. Оценка по ладоням на фото даёт 0,6–0,7 м.

## Пересборка

```bash
cd design/site/assets/3d/trophy-opus/src
blender -b --factory-startup --python build_trophy.py                  # -> ../trophy.glb (+ статистика)
#   варианты: -- --scheme accent (по умолчанию) | gold (латунная чаша) | silver (без латуни)
blender -b --factory-startup --python verify_glb.py -- ../trophy.glb    # обратный импорт и проверка нормалей
python3 glb_stats.py ../trophy.glb                                      # треугольники, материалы, размер, расширения

# рендеры (OptiX/CUDA подхватываются сами; 2k HDRI: https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/2k/studio_small_09_2k.hdr)
blender -b --factory-startup --python render_trophy.py -- --hdr /путь/к/studio_small_09_2k.hdr
python3 compose_dark.py ../trophy-dark-rgba.png ../trophy-dark.jpg && rm ../trophy-dark-rgba.png

# тестовая страница three.js с вшитым GLB
python3 make_test_page.py ../trophy.glb /tmp/trophy-test ../../hdr/studio_small_09_1k.hdr
```

Скрипты:

- `trophy_lib.py` — геометрия по замерам, материалы, гравировка (булево вычитание) и запекание текстуры сосны;
- `build_trophy.py` — экспорт GLB;
- `render_trophy.py` — рендеры;
- `compose_dark.py` — тёмный JPEG (Pillow);
- `verify_glb.py` — проверка через обратный импорт;
- `glb_stats.py` — разбор GLB без Blender;
- `make_test_page.py` — HTML-проверка.

Шрифт надписей — Noto Sans Bold (`/usr/share/fonts/truetype/noto/`, SIL OFL 1.1): контуры букв запечены в геометрию.
